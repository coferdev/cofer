# Cofer services

Bun · Hono · tRPC v11 · Drizzle (Postgres) · BullMQ (Redis) · viem 2.57.11 · grammY 1.46 · ZeroDev SDK (signer site).

## Run locally

```bash
cp .env.example .env            # fill RPC, factory/adapter addresses, bot token, secrets
bun install
bunx drizzle-kit migrate        # applies drizzle/0000_init.sql
BOT_MODE=polling ROLE=all bun src/index.ts
```

## Roles (`ROLE=`)

| Role | What it runs |
|---|---|
| `api` | Hono: `/trpc/*` (signer API), `/s/:token` (signer page), `/assets/signer.js` (built at boot with Bun.build), `/tg/webhook` (grammY, secret-token checked) |
| `bot` | Long polling, for local development only |
| `indexer` | viem `getLogs` polling up to head minus `CONFIRMATIONS`. Writes idempotent `chain_events` and projections (members, shares, proposals, epoch, revocations) |
| `keeper` | BullMQ schedulers: expire (60s), sweep queued/ready (30s), canonical Stock Token refresh (1h), holdings (5m), feed health (15m). Also runs the relay worker |
| `notifier` | One Telegram card per proposal, edited in place. Updates are coalesced to stay under 20 messages per minute per group |

## Layout

```
src/core/        pure logic (unit-tested): proposal + EIP-712, votes, shares, valuation, swap planning, geo, link tokens, Telegram login
src/services/    proposals.ts: create / typed data / verify + collect signatures / build execute calldata
src/relayer/     submits execute() (permissionless) and handles queued -> executed
src/indexer/     log watcher + projections
src/keeper/      scheduled jobs
src/notifier/    Telegram card rendering + edits
src/bot/         grammY plain bot, parsers, keyboards (url buttons only)
src/api/         tRPC router + Hono server
src/web/         signer page shell + browser bundle (Kernel v3.1 + passkey validator 0.0.3)
src/cards/       CardAdapter interface + StubCardAdapter (provider is out of band)
src/stocks/      canonical Stock Token list from the issuer's public API
src/chain/       addresses (verified 2026-10-25), clients, generated ABIs
drizzle/         SQL migration (generated by drizzle-kit)
scripts/         build-asset-list.ts (multisig listing batch from the canonical API)
test/            bun tests (42), incl. EIP-712 parity against compiled CoferPot bytecode run in-process
```

## Notes

- Never use viem's default RPC list for RHC: it includes a third-party endpoint. Set `RHC_RPC_URL`.
- The relayer key only pays gas for `execute()`. If the relayer is down, any member can submit the same calldata.
- Member actions (deposit, spend, exit, leave, revokeVote) are userOps from the member's own smart account, with gas paid by the ZeroDev/Alchemy paymaster.
